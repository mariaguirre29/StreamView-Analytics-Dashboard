# StreamView Analytics 🎬📊

## Análisis exploratorio y visualización del catálogo de contenidos

Proyecto desarrollado para la asignatura **Visualización de Datos**, cuyo objetivo es analizar un catálogo de películas y series mediante técnicas de análisis exploratorio, visualización de datos y construcción de un dashboard interactivo.

El proyecto busca identificar patrones asociados a la composición del catálogo, características de los contenidos, popularidad, valoración del público y desempeño económico.

---

# Objetivo del proyecto

Analizar información de películas y series para generar insights que apoyen la toma de decisiones relacionadas con:

- Adquisición de nuevos contenidos.
- Identificación de tendencias del catálogo.
- Comprensión de preferencias del público.
- Evaluación del desempeño de producciones audiovisuales.

---

# Contexto del problema

StreamView Analytics requiere comprender el comportamiento de su catálogo digital para responder preguntas como:

- ¿Qué tipo de contenido tiene mayor presencia?
- ¿Cuáles son los géneros y países predominantes?
- ¿Existe relación entre popularidad y valoración?
- ¿Qué producciones presentan mejor desempeño económico?

---

# Fuentes de datos

Se utilizaron dos datasets:

## Dataset de películas

Contiene información sobre:

- Título
- Géneros
- País
- Idioma
- Año de lanzamiento
- Popularidad
- Valoración promedio
- Presupuesto
- Ingresos

## Dataset de series

Contiene información sobre:

- Título
- Géneros
- País
- Idioma
- Año de lanzamiento
- Popularidad
- Valoración promedio

# Metodología

El proyecto fue desarrollado mediante las siguientes etapas:

## 1. Exploración inicial de datos (EDA)

Se realizó:

- Revisión de estructura de datasets.
- Análisis de tipos de variables.
- Identificación de valores nulos.
- Revisión de duplicados.
- Análisis descriptivo de variables.

## 2. Análisis exploratorio

Se analizaron:

- Distribución del catálogo.
- Géneros predominantes.
- Países e idiomas con mayor presencia.
- Relación entre popularidad y valoración.
- Relación entre presupuesto e ingresos.

## 3. Visualización

Se desarrollaron visualizaciones utilizando:

- Python
- Pandas
- Matplotlib
- Seaborn

Los gráficos permitieron identificar tendencias y generar hallazgos relevantes.

## 4. Dashboard interactivo

Se construyó un dashboard utilizando Power BI, incorporando:

- Indicadores principales.
- Filtros interactivos.
- Visualizaciones comparativas.
- Análisis del catálogo.

---

# Principales hallazgos

Entre los resultados obtenidos se identificaron:

- Diferencias en la composición del catálogo entre películas y series.
- Concentración de contenidos en determinados géneros, países e idiomas.
- La popularidad presenta una relación limitada con la valoración promedio.
- Las producciones con mayor inversión no necesariamente generan mayores ingresos.
